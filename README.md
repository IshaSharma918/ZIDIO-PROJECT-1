# 📈 Stock Market Analysis & Forecasting

This project is an interactive **Stock Market Analysis and Forecasting Dashboard** built using **Python and Streamlit**.

It allows users to upload a CSV dataset containing stock market data and analyze stock price trends using different visualization and forecasting techniques.

## 🚀 Features

* Upload stock market CSV data
* Visualize stock closing prices
* Calculate 50-day and 200-day moving averages
* Perform ADF stationarity testing
* Forecast prices using **ARIMA**
* Forecast prices using **Prophet**
* Predict prices using **LSTM**
* Evaluate ARIMA predictions using RMSE and MAE

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Plotly
* Statsmodels
* Scikit-learn
* Prophet
* TensorFlow/Keras
* Streamlit



## 🎯 Objective

The main objective of this project is to analyze historical stock market data and explore different **time-series forecasting techniques** such as **ARIMA, Prophet, and LSTM.**
